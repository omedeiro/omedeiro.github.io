# Budget Dashboard

Python-based tool for analyzing personal financial data.

## Overview

Automated data import, cleaning, and visualization for financial analysis.

## Features

- Multi-bank CSV import
- Automated data cleaning  
- Category analysis
- Monthly spending trends
