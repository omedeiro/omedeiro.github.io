A senior design project that develops an immersive virtual reality system with kinetic feedback for realistic arm and hand interactions in virtual environments.

![VR user testing session](/projects/vr-arm/vrUserTest.png)

## Technologies used

**VR development**

- **Unity 3D** — game engine and VR framework
- **C#** — primary programming language
- **HTC Vive** — VR headset integration

**Hardware integration**

- **Arduino** — device control
- **Servo motors** — force feedback actuation
- **Motor controller** — accurate positioning
- **IR sensors** — position detection

**User interface**

- **Custom VR UI** — intuitive virtual interfaces
- **Hand tracking** — Leap Motion integration
- **Voice commands** — speech recognition
- **Eye tracking** — gaze-based interaction
